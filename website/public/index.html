Getting started

Six steps from an npm install to one link a reviewer can follow.

  1. Install diffwalk

    diffwalk is published on npm and runs on Node.js 20 or newer. Install it globally, or run any command through npx diffwalk without installing anything.

    TERMINAL
    $npm install --global diffwalk
    RequiresNode.js 20+Gitor npx diffwalk

  2. Capture the working tree

    Run diffwalk inside the Git repository you want to explain. It captures changes relative to HEAD into a timestamped walk under .diffwalk/.

    TERMINAL
    $diffwalk inspect

    Captured 370 change blocks across 24 files to

    .diffwalk/20260831T063842Z-a7c9e4f2/capture.json

    In the walkcapture.json — machine-ownedexplanations.yaml — yours to edit

  3. Author the reading order

    Edit only explanations.yaml in the current walk. Write Markdown, arrange sections, and attach each explanation to exact change IDs.

    .diffwalk/<walkId>/explanations.yaml
    title: Stop the double charge
sections:
 - title: Charge path asks first
   steps:
    - text: |
        The lookup runs before the gateway.
      changes: [change-009]
    diffwalk check → diffwalk view
    Thendiffwalk check — every change explainedevery patch still applies

  4. Preview it locally

    diffwalk view renders the review in memory and opens it on a loopback-only port. No HTML file is written and nothing leaves the machine.

    TERMINAL
    $diffwalk view

    Viewing 6 sections at http://127.0.0.1:53421

  5. Publish one link

    diffwalk publish uploads the document — not the HTML — to the review service and prints an unlisted link.

    TERMINAL
    $diffwalk publish

    Published 6 explanation sections to

    https://review.diffwalk.dev/r/P_8OK1RGULn2Wx2p6u1LuQ

  6. Follow the explanation

    The review keeps explanations, diagrams, and exact diffs in one ordered tree. Reviewers can fold sections and switch diff layouts without losing their place.
