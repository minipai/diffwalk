Install diffwalk

Install diffwalk globally, or run any command through npx diffwalk without installing anything.

TERMINAL
$npm install --global diffwalk
RequiresNode.jsGitor npx diffwalk

“Use diffwalk to explain this change.”

Give your coding agent this instruction. It captures and explains the change; you choose when to view or publish the review.

  1. The agent captures the working tree

    The agent runs diffwalk inside the Git repository you want to explain. It captures the working tree against HEAD by default, or another revision you choose, into a timestamped walk under .diffwalk/.

    TERMINAL
    $diffwalk inspect

    Captured 370 change blocks across 24 files to

    .diffwalk/20260831T063842Z-a7c9e4f2/capture.json

    In the walkcapture.json — machine-ownedexplanations.yaml — yours to edit

  2. The agent authors the reading order

    The agent edits only explanations.yaml in the current walk. It writes Markdown, arranges sections, and attaches each explanation to exact change IDs.

    .diffwalk/<walkId>/explanations.yaml
    title: Stop the double charge
sections:
 - title: Charge path asks first
   steps:
    - text: |
        The lookup runs before the gateway.
      changes: [change-009]
    diffwalk check → diffwalk view
    Thendiffwalk check — every change explainedevery patch still applies

  3. View it locally

    diffwalk view renders the review in memory and opens it on a loopback-only port. No HTML file is written and nothing leaves the machine.

    TERMINAL
    $diffwalk view

    Viewing 6 sections at http://127.0.0.1:53421

  4. Publish a link (optional)

    When you want to share the review, diffwalk publish uploads it and prints a share link.

    TERMINAL
    $diffwalk publish

    Published 6 explanation sections to

    https://review.diffwalk.dev/r/P_8OK1RGULn2Wx2p6u1LuQ

  5. Follow the explanation

    The review keeps explanations, diagrams, and exact diffs in one ordered tree. Reviewers can fold sections and switch diff layouts without losing their place.
